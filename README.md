# Kokona MDReader

轻量的纯前端 Markdown 阅读器，通过浏览器将 `.md` 文件渲染为网页
> **关于代码质量**：本项目为作者设计的自用小工具，代码可能不够优雅，欢迎接手。

## 简介

Kokona MDReader 是一个单文件 HTML 小工具。它通过 URL 参数指定要加载的 Markdown 文件，使用 `fetch` 获取内容，并在浏览器端完成解析与渲染。适合部署在任意静态服务器上，用于快速查阅文档、笔记或项目说明，而无需任何后端。

## 快速开始

### 1. 获取文件

将本项目的 HTML 文件保存为 `mdr.html`（或任意名称），放置在你的静态服务器目录中。

### 2. 准备 Markdown 文件

如果不加URL参数，网页会自动读取同目录的`/md/sample.md`

或者通过URL参数进行访问：在服务器上创建一个目录（例如 `/md/`），并将你的 `.md` 文件放入其中：

```
/your-site/
├── index.html
└── md/
    ├── sample.md
    └── notes/
        └── hello.md
```

### 3. 访问阅读器

在浏览器中打开：

```
https://your-site.com/mdr.html?file=/md/sample.md
```

或省略 `.md` 后缀：

```
https://your-site.com/mdr.html?file=/md/sample
```

如果不带任何参数，默认会尝试加载 `/md/sample.md`。

## URL 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `file` | 否 | 要加载的 Markdown 文件路径。支持相对路径和绝对路径。若省略 `.md` 后缀，会自动补全。默认为 `/md/sample.md`。 |

**示例：**

```
?file=/md/sample.md
?file=notes/hello
?file=/docs/guide.md
```
> 注意：`file` 参数是相对于当前页面所在路径解析的。如果阅读器不在根目录，请使用相对路径或完整的绝对路径。

## 已知问题

- 不支持嵌套列表的深层缩进解析（仅支持一层嵌套）。
- 不支持任务列表（`- [ ]` / `- [x]`）。
- 不支持脚注、目录自动生成、数学公式等扩展语法。
- 表格解析要求分隔行至少包含一个 `-` 和一个 `|`。
- 图片和链接的 URL 中若包含空格或括号，可能无法正确解析。

## 浏览器兼容性

支持所有现代浏览器，不支持 IE。
